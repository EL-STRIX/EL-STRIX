## [0.1.0] - 2026-07-26

### Added
- Initialized complete repository folder structure.
- GitHub Actions workflows for profile updates, linting, security analysis, and automated releases.
- Asset pipeline with light and dark mode SVG dynamic banner templates.
- Python engine scripts (`github.py`, `generator.py`, `renderer.py`, `utils.py`, `main.py`).
- Documentation, testing harness, issue/PR templates, and project configuration files.
